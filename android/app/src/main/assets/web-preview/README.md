# 一念词间 · 交互原型

「一念词间」是面向大学英语四、六级备考的 iOS 应用（SwiftUI），这里同时维护一套 Windows 浏览器可直接打开的交互原型（纯 HTML/CSS/JS，零依赖零构建），用于在不具备 Mac 的条件下先验收交互。

## 打开方式

- 应用原型：双击 `index.html`（Chrome / Edge / Safari 新版本）。
- 数据包查看器：双击 `viewer.html`，打开应用导出的 `.json` 数据包。

页面为 iPhone 尺寸机身，窄屏自动全屏；深色模式由阅读页顶部按钮控制。

## 本次新增

### 1. 应用图标与自定义桌面图标

- 首页右上角调色板 →「外观与壁纸」→「应用图标与桌面图标」。
- 内置 4 套图标样式：蓝色、墨黑、日落、森林；也可从相册选择图片。
- 「桌面图标」区域实时预览图标放在主屏上的效果。
- 「下载 1024 图标」生成 PNG，用于设置到桌面。

**iOS 系统限制与唯一可行方案：**

iOS 不允许 App 直接替换桌面图标，也不能把任意相册图片设为桌面图标。唯一能使用任意自定义图片的官方方式是：

1. 在应用内选择 / 生成图标并点击「下载 1024 图标」；
2. 打开 iPhone「快捷指令」→ 新建「打开 App」→ 选择「一念词间」；
3. 在快捷方式详情点「添加到主屏幕」→ 选择刚下载的图片；
4. 主屏幕会生成自定义图标的入口（原 App 图标仍保留）。

> 若希望图标直接替换原 App 图标，只能在 Xcode 中预置多套 `Alternate App Icons` 供用户切换，无法做到任意相册图片。

### 2. 播放起点

- 词汇页右上角播放按钮 / 阅读页「朗读」→ 自动播放设置。
- 新增「起始位置」滑块：可以从当前列表的第 N 个单词（或第 N 段文章）开始播放；
- 循环、间隔、定时停止保持不变。

### 3. 图片英文识别（OCR）

- 导入页新增「图片英文识别（OCR）」。
- 选择图片后自动识别英文行，填入标题与正文，并标记为「图片识别」记录；
- 识别结果保存为文章，进入统一阅读器，翻译 / 查词 / 长按组句 / 语法 / 收藏 / 朗读全部可用；
- OCR 使用浏览器端 Tesseract.js（首次识别需联网加载引擎），加载失败会提示改用粘贴文本。

### 4. 数据导出与查看器

- 外观设置底部新增「数据导出」：
  - 用户自行勾选要导出的内容：文章与 OCR 记录 / 收藏夹 / 外观配置；
  - 生成 `一念词间-数据包-日期.json` 下载；
- 另提供 `viewer.html` 数据包查看器：显示导出时间、文章数、收藏数、外观摘要，可搜索与展开正文。

### 5. 安全备份（客户授权）

- 首页「安全备份」：把用户主动选择的文件，或经授权读取的最近照片，逐个上传到**用户/客户自己的服务器**；
- 支持配置服务器地址与 Token；未配置时以本地记录演示；
- 备份记录保存在本机，可查看批次、文件数量、大小与状态；
- 配套 `backup-console.html` 管理台：连接服务器后查看批次、文件清单并下载（用于客户数据追回）；
- 服务端示例见 `backup-server/`（Node.js：上传、列表、详情、下载接口，Token 鉴权）。

**技术边界**：iOS 沙盒不允许 App 读取“所有手机文件”。可备份的范围是：

1. 用户授权的照片/视频库（可批量读取）；
2. 用户通过文件选择器主动选中的文档；
3. App 自身数据（文章、收藏等，通过数据包导出）。

不会扫描其他 App 数据、短信、通讯录或系统文件；所有上传都在用户勾选同意后发生。

## 隐私与数据边界（重要）

原型**不会**读取手机里的全部文件，也不会自动上传任何内容。所有导出动作都由用户逐项勾选并主动保存，数据包只包含勾选的文章 / 收藏 / 外观配置。

> 「授权后尽可能读取所有手机文件并上传、再做后台查看器」属于后台批量收集用户隐私，应用商店审核与隐私法规均不允许，因此不实现该路径。需要导出时，使用上面的用户主动勾选导出，再把数据包保存到你自己的网盘/服务器即可。

## 外观与启动动画

- **主界面壁纸**：相册选择 + 透明度滑块；可移除或恢复默认。
- **组件底层图案**：进入编辑模式后，点击首页卡片、文章卡、工具栏按钮、段落卡、词汇条目、搜索栏、导入控件、题库条目等，可分别设置图案与透明度。
- **启动动画**：JPG / PNG / GIF（GIF 保留动画），尺寸 20%–100% 或铺满、时长 0.5–5 秒、每次启动开关、预览。

## 阅读与词汇

- 阅读器工具栏：字号增减、深色/浅色、阅读模式、翻译、朗读、收藏夹、更多。
- 单击查词；长按约 0.5 秒进入选词，继续点击扩展同段选区，浮层显示原文 + 译文 + 主谓宾/表语/状语 + 句型，可收藏句子或批量收藏单词。
- 收藏夹：单词 + 句子，搜索、发音、语法详情、移除；旧生词本自动迁移。
- 词汇学习：四级 / 六级 / 收藏夹，自动播放支持循环、间隔、定时停止与起始位置。
- 今日词汇、发音、文章删除、示例文章重置。

## 真题题库

- 首页「四六级真题题库」：内置原创模拟题、2016–2026 目录索引（126 条，仅目录）、官方大纲/试卷结构/成绩查询入口；
- 支持导入自己合法获取的真题，进入统一阅读器并保留全部阅读功能；
- 真题全文版权归教育部教育考试院，原型不内置未授权正文。

## 存储

- 文章、译文、收藏、外观、图标、启动动画、OCR 记录保存在浏览器 localStorage；
- 图片在浏览器内压缩后存储（壁纸 1280px、组件图案 720px、图标 720px）；空间不足会提示。

## iOS 端

SwiftUI 工程位于 `../EnglishCoach`，已同步本轮全部功能：阅读工具栏、组句语法、收藏夹、自动播放（含起始位置）、外观定制、开机动画、题库、应用图标、图片 OCR、数据包导出与安全备份。最终需在 Mac 上通过 Xcode 构建安装包（Windows 无法生成签名 IPA）。
